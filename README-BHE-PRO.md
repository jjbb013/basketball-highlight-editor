# BHE Pro：基于 BHE 的 macOS 增强版

BHE Pro 是 [BHE（Basketball Highlight Editor）](README.md) 的二次开发版本，专注于 macOS 桌面端，并在原版「自动找出疑似进球 → 人工审核 → 导出集锦」的流程之上，增加了**视频封面、背景音乐、人物身份识别、跨天合并导出**等能力。

- 独立应用：与原版 BHE 可以同时安装，互不影响（Bundle ID `com.courtside.bhepro`，数据目录 `Application Support/BHE Pro/Projects`）
- 平台：macOS（Apple Silicon + Intel，DMG 安装包）
- 运行方式不变：完全本地分析，原视频不上传

> 最新已发布的安装包见 [Releases · v0.1.17-macos.1](https://github.com/jjbb013/basketball-highlight-editor/releases/tag/v0.1.17-macos.1)，包含人物分析区、人物复核页、跨天合并导出、视频封面与背景音乐。

## 与原版 BHE 的差异一览

### 1. 独立的 macOS 应用

应用名改为 **BHE Pro**，使用独立的 Bundle ID 与数据目录，可以和原版 BHE 装在同一台 Mac 上分别打开。项目数据、草稿、导出记录互不可见，避免混淆两个版本。

### 2. 自动视频封面（可选）

- 导出时可开启封面，**默认在成片开头加 3 秒封面**（时长可改）。
- 提供三种封面样式：**球场（court）**、**海报（poster）**、**照片（photo）**。
- 封面内容自动取自人物标签与项目信息，支持自定义：标题、副标题、强调色、本地背景图。

### 3. 自动背景音乐（可选）

- 导出时可为成片叠加运动风格 BGM，**默认 20% 音量**作为背景，现场原声保留，音量可调。
- 内置多种运动类型：Electronic drive（电子律动）、Hip-hop bounce（嘻哈弹跳）、Rock pulse（摇滚脉冲）。
- 支持选择**本地音频文件**作为自定义 BGM。

### 4. 球员身份识别（新增算法）

针对业余比赛球员**没有球衣号码**的场景，新增基于 YOLO 的人物识别管线（`scripts/identify_players.py`）：

- **YOLO 检测球与篮筐**（与原版一致），结合 **YOLO Pose** 提取画面中球员的关键点；
- 按球员的**当场外观**（体型、肤色、发型、脸型、衣着）提取特征并聚类成「当场身份」，不需要提前注册人脸；
- 在每个进球片段里推断**进球前最后一个触及球的人**，与身份关联，得到「这个球是谁投进的」；
- **命名传播**：当你把某个身份命名为「Will」，该身份所有自动识别的进球会一次性标成 Will；之后对单条的人工改派不会被命名覆盖（人工优先）。

配套的两个新交互：

- **人物分析区（可选）**：导入页第 2 步检测区域新增紫色第三区域，覆盖画面中球员活动范围，人物识别与最后触球分析优先使用；不设置则自动回退到投篮分析区。
- **人物复核页**：审核页顶部可在「投篮 / 人物」两个视图间切换。人物视图按身份分组展示每个进球的触球时间与自动归属，可以：
  - 一键把整组命名为某名球员（命名传播）；
  - 按「待复核 / 已命名」筛选，聚焦没确认的身份；
  - 对单条进球改派或清除修正。

### 5. 跨天合并导出

导出页可以把**历史项目**（例如昨天和今天、同一场地同一批球员的两个项目）一起选中导出，不同日期的同名球员进球合进同一个集锦。历史项目只读，不会被修改。

### 6. 安装与签名说明

- DMG 为本地构建的 **Ad Hoc 签名、未公证**版本：首次打开请在「应用程序」里右键 →「打开」，或在「系统设置 → 隐私与安全性」中允许打开。
- 无内置自动更新；新版本通过 GitHub Releases 手动下载替换。

## 开发

二次开发代码在分支 `feature/player-analysis-zone-people-review`（基于 `main`）。结构与原版一致：

- `apps/desktop`：Flutter macOS 客户端
- `engine/python`：分析/导出引擎（Python）
- `scripts/identify_players.py`：人物识别入口脚本（YOLO Pose + 最后触球 + 当场外观聚类）

测试：

```bash
# Python 引擎
python -m pytest -q
# Flutter 客户端
cd apps/desktop && flutter test --concurrency=1
```
